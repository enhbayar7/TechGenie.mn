FIREBASE ХОЛБОХ ЗААВАР (Techgenie)
==================================

Үр дүн: хэрэглэгч ямар ч утаснаас захиалга өгөхөд таны админ самбарт
шууд харагдана. Хэрэглэгч зөвхөн өөрийн КОДООР явц, баталгаагаа харна.
Зардал: үнэгүй (Firebase Spark төлөвлөгөө хангалттай).

АЛХАМ 1. Firebase төсөл үүсгэх
  1) console.firebase.google.com руу Gmail-ээрээ орно.
  2) "Create a project" (Add project) дарна. Нэр: techgenie
  3) Google Analytics-ийг унтраагаад (Disable) Create дарна.

АЛХАМ 2. Өгөгдлийн сан (Firestore) үүсгэх
  1) Зүүн цэсээс Build → Firestore Database → Create database.
  2) Байршил: asia-southeast1 (Сингапур) эсвэл asia-east1 (Тайвань).
  3) "Start in production mode" сонгоод Create дарна.

АЛХАМ 3. Аюулгүй байдлын дүрэм (ЧУХАЛ)
  1) Firestore Database → "Rules" таб руу орно.
  2) Бүх текстийг устгаад, firestore.rules файлын агуулгыг хуулж тавина.
  3) Файл доторх  ADMIN_EMAIL@gmail.com  гэснийг
     ӨӨРИЙН админ имэйлээр солино (АЛХАМ 4-д үүсгэх имэйлтэй яг ижил).
  4) "Publish" дарна.

АЛХАМ 4. Админы нэвтрэх хаяг үүсгэх
  1) Build → Authentication → "Get started".
  2) Sign-in method → Email/Password → Enable → Save.
  3) Users таб → "Add user" → өөрийн имэйл болон хүчтэй нууц үг.
     (Энэ имэйл АЛХАМ 3-ын дүрэм дэх имэйлтэй ижил байх ёстой.)
  4) Authentication → Settings → Authorized domains → "Add domain" →
     өөрийн Vercel хаягийг нэмнэ (жишээ нь techgenie.vercel.app).

АЛХАМ 5. Сайтыг Firebase-тэй холбох
  1) Төслийн тохиргоо (зүүн дээд буланд шүдний цэг ⚙ → Project settings).
  2) General таб → доош гүйлгээд "Your apps" → </> (Web) дүрс → нэр: techgenie-web
     → Register app.
  3) Гарч ирсэн firebaseConfig = { ... } хэсгийг хуулна.
  4) Энэ хавтсан дахь firebase-config.js файлыг нээж,
       window.FIREBASE_CONFIG = null;
     гэсэн мөрийг устгаад хуулсан тохиргоогоо window.FIREBASE_CONFIG = {...}; хэлбэрээр тавина.

АЛХАМ 6. Сайтыг шинэчлэх
  GitHub дээр firebase-config.js болон index.html файлаа солиод Commit хийнэ.
  Vercel автоматаар шинэчилнэ (1–2 минут).

АЛХАМ 7. Шалгах
  1) Утсаараа сайтад орж туршилтын захиалга өгнө (кодоо тэмдэглэнэ).
  2) Компьютер дээрээ  сайтаа/#admin  руу орж, АЛХАМ 4-ийн имэйл, нууц үгээр нэвтэрнэ.
  3) Захиалга харагдах ёстой. Статус өөрчилж, "Явц шалгах" хэсэгт кодоор шалгана.

ТҮГЖЭЭЛТ / АНХААРАХ
  - Админ нэвтрэх хэсэг: сайтынхаа хаяг/#admin  эсвэл footer-ийн "Админ самбар".
  - Хэрэглэгчид ЗӨВХӨН кодоор явцаа харна. Утасны дугаар, имэйл бусдад харагдахгүй.
  - Нэг цагт 2-оос олон захиалга авахгүй. Дүрэм (firestore.rules) болон кодын
    SLOT_CAP тоог (2) хамт солино.
  - Нууц үгээ бусдад бүү өг. Нууц үг мартвал Authentication → Users дээрээс сэргээнэ.
  - Сурталчилгааны робот (spam) захиалгаас хамгаалахын тулд дараа нь
    Firebase "App Check" тохируулж болно.
