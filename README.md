УТАСНЫ ЗУРАГ ОРУУЛАХ ХАВТАС
===========================

Энд утасны жинхэнэ зургаа тавивал сайт автоматаар хэрэглэнэ.
Зураг байхгүй загварт сайт одоогийн зурсан дүрсийг харуулна, тиймээс бүгдийг нэг дор оруулах шаардлагагүй.

ДҮРЭМ
- Файлын нэр доорх жагсаалтаар яг ижил байна (жижиг үсэг, зайгүй, зураасаар).
- Төрөл: .png (тунгалаг дэвсгэртэй нь хамгийн сайн), эсвэл .webp, .jpg
- Хэмжээ: өндөр нь 600–900 px орчим, нэг зураг 300 KB-аас бага байвал сайт хурдан ачаалагдана.
- Бүх зургийг нэг талаас (жишээ нь бүгдийг арын талаас нь) ижил хэмжээтэй тавьбал харагдац жигд болно.
- GitHub дээр img хавтсанд файл нэмбэл Vercel автоматаар шинэчилнэ.

НҮҮР ХУУДСЫН ЗУРАГ (заавал биш)
- Өөрийн гоё зураг (дэлгүүрийн дотор, техникч ажиллаж буй, эсвэл утасны сурталчилгааны зураг) тавихыг хүсвэл
  img хавтсанд  hero.png  (эсвэл hero.webp, hero.jpg)  нэрээр хийнэ.
- Тавьсан тохиолдолд нүүр хуудасны баруун талын зураг автоматаар энэ зургаар солигдоно.
- Хэмжээ: ойролцоогоор 900 x 900 px (дөрвөлжин) эсвэл 900 x 800 px, 300 KB-аас бага.

НҮҮР ХУУДСЫН 2-Р СЛАЙД (хөдөлгөөнт)
  Өөрийн GIF эсвэл видеог тавибал 2-р слайдын анимацийг орлоно:
  slide2.gif  (эсвэл slide2.webp, slide2.png, slide2.jpg)  эсвэл  slide2.mp4 (дуугүй, давтагдана)
  Тохиромжтой хэмжээ: өргөн 800–1000 px, нэг файл 2 MB-аас бага. Байхгүй бол сайтын QR уншуулах анимаци харагдана.
